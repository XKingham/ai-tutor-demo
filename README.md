# 智研学堂 · 公开技术演示

三个虚拟学员使用同一套公开数据结构示例讲义。选择学习目标与时间、提交诊断和练习后，浏览器计算知识点状态、下一步任务与教师学情。切换档案可对比同一问题的本地真实模型回放，回放与当前浏览器作答分开。页面内存保存本次演示状态，刷新或点按重置可清除。

回放来自本地 DeepTutor v1.7.4 原生 Chat Agent。强化档的例图边数由课程核算，在答复旁单独展示。

访问 [GitHub Pages 演示](https://xkingham.github.io/ai-tutor-demo/)。

## 本地构建

```bash
node --test
node scripts/build.mjs
```

产物为 `dist/`，可部署到任意静态站点子路径。资源和页面内导航使用相对路径。本仓库使用独立 HTML、CSS 和 JavaScript，发布工作流只上传构建后的静态资源。
